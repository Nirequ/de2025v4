# Модуль 3. Авторизация пользователей

Проектная документация WPF-приложения авторизации, реализованного на C# (.NET 8).

## 1. Функциональное назначение

Приложение предоставляет интерфейс авторизации пользователей информационной
системы транспортной компании «АТП-1». Реализуются роли «Администратор» и
«Пользователь». Поддерживается принудительная смена пароля при первом входе,
автоматическая блокировка после трёх подряд неуспешных попыток, автоматическая
блокировка по истечении 30 дней неактивности, а также администрирование
учётных записей (добавление, изменение, разблокировка, сброс пароля).

Хранилище данных — SQLite. Если в каталоге `module2/` присутствует БД,
сформированная модулем 2, приложение использует её. Иначе создаёт собственный
файл `app.db` в каталоге сборки.

## 3. Структура таблицы «Пользователи»

```sql
CREATE TABLE Пользователи (
    id_пользователя         INTEGER PRIMARY KEY AUTOINCREMENT,
    логин                   TEXT    NOT NULL UNIQUE,
    пароль_хеш              TEXT    NOT NULL,
    id_роли                 INTEGER NOT NULL,
    id_сотрудника           INTEGER UNIQUE,
    дата_создания           DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    дата_последнего_входа   DATETIME,
    число_неудачных_попыток INTEGER NOT NULL DEFAULT 0,
    признак_блокировки      INTEGER NOT NULL DEFAULT 0,
    признак_первого_входа   INTEGER NOT NULL DEFAULT 1,
    FOREIGN KEY (id_роли) REFERENCES Роли(id_роли)
);
```

Справочник `Роли` содержит две предопределённые записи: «Администратор» и
«Пользователь».

## 4. Сценарии работы

### 4.1. Вход в систему

1. Пользователь вводит логин и пароль и нажимает «Войти».
2. Сервис проверяет заполненность полей. Пустое поле → ошибка
   *«Поля „Логин“ и „Пароль“ обязательны для заполнения.»*
3. По логину ищется учётная запись. Если её нет, либо пароль не совпадает —
   выводится требуемое экзаменационным заданием сообщение
   *«Вы ввели неверный логин или пароль. Пожалуйста проверьте ещё раз
   введенные данные»* и увеличивается счётчик неудачных попыток.
4. При достижении трёх неудачных попыток подряд устанавливается признак
   блокировки. Дальнейшие попытки получают сообщение
   *«Вы заблокированы. Обратитесь к администратору»*.
5. Если последний успешный вход (или дата создания, если входов не было)
   старше 30 дней — учётная запись блокируется автоматически перед проверкой
   пароля.
6. При успешной проверке выводится сообщение
   *«Вы успешно авторизовались»*, счётчик неудачных попыток сбрасывается,
   фиксируется дата последнего входа.
7. Если у учётной записи установлен признак «первого входа» — открывается
   форма смены пароля. Доступ к рабочему месту возможен только после успешной
   смены.
8. В зависимости от роли открывается окно администратора либо обычного
   пользователя.

### 4.2. Смена пароля

1. Поля «Текущий пароль», «Новый пароль», «Подтверждение нового пароля»
   обязательны.
2. Текущий пароль проверяется через `PasswordHasher.Verify`.
3. Новый пароль и подтверждение сравниваются как строки. Проверяется длина
   (минимум 4 символа) и отличие от текущего пароля.
4. При успехе хеш заменяется в БД, признак «первого входа» снимается,
   выводится сообщение об успешной смене пароля.

### 4.3. Администрирование

* «Добавить пользователя» — открывает диалог. Проверка уникальности логина в
  репозитории. При дубликате выводится сообщение
  *«Пользователь с указанным логином уже существует в базе данных.»*
* «Изменить выбранного» — меняет логин, роль, признак блокировки. Можно
  задать новый пароль; при этом признак «первого входа» восстанавливается,
  чтобы пользователь сменил его при следующем входе.
* «Снять блокировку» — мгновенно очищает признак блокировки и счётчик
  неудачных попыток у выбранной учётной записи.
* «Сбросить пароль» — присваивает временный пароль и принуждает к смене.
* «Обновить» — повторно загружает данные таблицы.

## 5. Описание ключевых методов

### 5.1. `PasswordHasher`

| Метод                              | Параметры                          | Назначение                                     |
| ---------------------------------- | ---------------------------------- | ---------------------------------------------- |
| `string Hash(string password)`     | `password` — пароль в открытом виде | Создаёт хеш PBKDF2-HMAC-SHA256 (200000 итераций). |
| `bool Verify(string p, string s)`  | `p` — пароль, `s` — хранимый хеш    | Проверяет соответствие пароля сохранённому хешу. |

### 5.2. `UserRepository`

| Метод                                                                                        | Назначение                                                                       |
| -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `void EnsureSchema()`                                                                        | Создаёт таблицы и базовые роли, если их нет.                                     |
| `User? FindByLogin(string login)`                                                            | Возвращает учётную запись по логину или `null`.                                  |
| `IReadOnlyList<User> List()`                                                                 | Возвращает список всех пользователей.                                            |
| `int Insert(string login, string passwordHash, string roleName)`                             | Создаёт новую запись. При дубликате логина выбрасывает `InvalidOperationException`. |
| `void Update(int userId, string? login, string? roleName, bool? isBlocked, string? hash, bool? mustChangePassword)` | Обновляет выбранные поля.                            |
| `(int Attempts, bool BlockedNow) RegisterFailedAttempt(int userId)`                          | Фиксирует неудачную попытку, при необходимости включает блокировку.              |
| `void RegisterSuccessfulLogin(int userId, DateTime? at)`                                     | Сбрасывает счётчик и записывает дату последнего входа.                           |
| `bool ApplyInactivityLockoutIfNeeded(int userId, DateTime? now)`                             | Если активность отсутствует более 30 дней — блокирует запись.                    |
| `string GetPasswordHash(int userId)`                                                         | Возвращает текущий хеш пароля.                                                   |
| `bool HasAdministrator()`                                                                    | Проверяет наличие хотя бы одного администратора в системе.                       |

### 5.3. `AuthService`

| Метод                                                                                          | Назначение                                              |
| ---------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| `AuthResult Authenticate(string login, string password)`                                       | Полный сценарий авторизации (см. §4.1).                 |
| `OperationResult ChangePassword(int userId, string current, string @new, string confirmation)` | Смена пароля с валидацией.                              |
| `OperationResult CreateUser(string login, string password, string roleName)`                   | Создание учётной записи администратором.                |
| `OperationResult UpdateUser(int userId, string? login, string? roleName, bool? isBlocked, string? newPassword)` | Универсальное редактирование.        |
| `OperationResult Unblock(int userId)`                                                          | Сокращение для `UpdateUser` со снятием блокировки.       |

### 5.4. Окна WPF

| Класс                  | Назначение                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| `App`                  | Композиционный корень. Создаёт SQLite-репозиторий, проверяет наличие администратора, открывает `LoginWindow`. |
| `LoginWindow`          | Форма авторизации. Валидация полей, отображение сообщений, переход к смене пароля или к рабочему столу. |
| `PasswordChangeWindow` | Диалог смены пароля. Валидация трёх полей.                                                  |
| `AdminWindow`          | Рабочее место администратора. Список пользователей и операции над ним.                      |
| `UserEditDialog`       | Диалог добавления / редактирования пользователя.                                            |
| `UserWindow`           | Рабочее место рядового пользователя. Информация о сеансе и смена пароля.                    |

## 7. Тестирование

Все ключевые сценарии покрыты xUnit-тестами в проекте `Module3.Tests`:

* `PasswordHasherTests` — формат хеша, рандомизация соли, проверка верного и
  неверного пароля, отказ при некорректном формате.
* `AuthServiceTests` — успех, валидация пустых полей, блокировка после трёх
  попыток, разблокировка администратором, автоблокировка по неактивности,
  смена пароля (все ветки), запрет дубликата логина, обновление роли.

Запуск: `dotnet test module3/Module3.sln`. Текущий результат — 18 / 18.

## 8. Дефолтный администратор

При первом запуске, если в БД отсутствует хотя бы один администратор,
создаётся учётная запись `admin` / `Admin#2025`. При первом входе система
потребует сменить пароль.
